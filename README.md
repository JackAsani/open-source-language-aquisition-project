# 🌍 The Open Source Language Acquisition Project

This project is a collection of software tools that aids in the process of language acquisition.

The aim is to give learners at least a basic option if similar software products on the market don't currently support ones target language or desired feature.

---
## Current OSLAP Tools

### Parrot Mirror
A chrome extension that helps repeadtedly practice native-pronunciation while watching youtube videos
